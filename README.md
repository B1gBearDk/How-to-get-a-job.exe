# Cybersecurity & Systems Labs

Small, self-contained scripts and services from my BSc Cyber Security coursework (Erhvervsakademi København EK/KEA), built as group assignments. Everything here has actually been run, not just written each project's README includes a real log excerpt as evidence.

## Projects

- **[raw-socket-webserver](./raw-socket-webserver)** — a minimal HTTP/1.1 server built directly on Python sockets (no framework), with custom Apache-style access logging.
- **[cpu-monitor](./cpu-monitor)** — a lightweight Linux monitoring daemon that logs CPU utilization on a fixed interval, structured for downstream log correlation.
- **[windows-service-auto-restarter](./windows-service-auto-restarter)** — a PowerShell watchdog, packaged as a real persistent Windows Service (via WinSW), that detects and auto-restarts stopped services.
